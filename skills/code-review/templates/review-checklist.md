# Review checklist

- The change matches the stated requirement.
- Inputs, paths, credentials, and authorization are validated.
- Failures preserve data and return actionable errors.
- Concurrent and repeated execution is safe.
- Tests cover happy paths, edge cases, and regressions.
- Logs and diagnostics do not expose secrets.
- User-facing behavior and operational changes are documented or observable.
- Findings are backed by evidence and precise file references.
